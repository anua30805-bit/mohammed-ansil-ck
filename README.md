A personal portfolio website for **Mohammed Ansil**, aspiring AI Content Creator, designed and developed directly according to the reference poster design and color specifications.

---

## 🎨 Design System & Reference Match

This portfolio faithfully adopts the exact visual aesthetic, color palette, and layout principles shown in the provided reference photos:

1. **Color Palette**:
   - **Canvas Background**: Editorial Warm Studio Ivory / Cream (`#F4F3EE` & `#FAF9F5`)
   - **Primary Accent**: Electric Cobalt / Royal Blue (`#0038FF`)
   - **Typography Black**: Stark Ink Charcoal (`#0A0C10` / `#0C0E12`)
   - **Ambient Glows**: Soft diffuse radial royal blue lighting (`rgba(0, 56, 255, 0.35)`) in top-right and bottom-left quadrants
   - **Subtle Grid**: Editorial vertical guideline overlay evoking an art director's layout grid

2. **Typography**:
   - **Display / Big Titles**: *Bebas Neue* & *Oswald* (tall, ultra-condensed, high impact)
   - **Subheads & Badges**: *Space Grotesk* (tracked uppercase technical sans-serif)
   - **Body**: *Inter* (clean, legible grotesk)

3. **Graphic Motifs**:
   - Iconic cobalt blue play triangles (`▶`) preceding titles and list items
   - Solid electric blue horizontal accent rules (`background: #0038FF; height: 2px;`)
   - 3D layered hero stage:
     - Layer 1: Solid black text behind silhouette
     - Layer 2: Mohammed Ansil's silhouette portrait with electric blue aura
     - Layer 3: Stroked / outline text foreground cut-through
   - Interactive 3D parallax tilt on mouse hover

## 💻 How to View & Deploy

### Quick Local Preview
Simply double click `index.html` or open it with any web browser (Chrome, Edge, Safari, Firefox). No build steps or node dependencies required!

### One-Click Deployment
- **GitHub Pages**: Push this folder to a GitHub repository and enable Pages under *Settings > Pages*.
- **Vercel / Netlify**: Drag-and-drop this entire folder onto [vercel.com](https://vercel.com) or [netlify.com](https://app.netlify.com/drop) for instant deployment with an SSL domain.
